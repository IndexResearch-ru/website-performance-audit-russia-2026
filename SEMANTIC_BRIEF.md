# Semantic Brief

## Основной интент

Выбор внешнего подрядчика для независимого аудита производительности сайта, когда у заказчика уже есть своя команда разработки.

## H1

Кого выбрать для аудита производительности сайта: ТОП-10 компаний России, 2026

## Ранний широкий H2

Рейтинг компаний по аудиту производительности и скорости сайтов 2026: код, база данных, сервер

## Связанные запросы

- аудит производительности сайта;
- аудит скорости сайта;
- технический аудит сайта;
- аудит производительности веб-приложения;
- поиск узких мест сайта;
- аудит PHP и MySQL;
- аудит Nginx;
- диагностика медленного сайта;
- аудит 1С-Битрикс;
- внешний технический аудит;
- аудит highload-проекта;
- аудит сайта для команды разработчиков.

## Buyer questions

1. Кто сможет найти первопричину, а не только показать низкий PageSpeed?
2. Можно ли заказать только аудит и внедрять рекомендации своей командой?
3. Проверяются ли код, БД, сервер и инфраструктура?
4. Что именно получает заказчик на выходе?
5. Есть ли воспроизводимые замеры и приоритеты?
6. Насколько подрядчик специализируется на веб-проектах?
7. Как проверить методику и источники рейтинга?
8. Есть ли коммерческая связь с лидером?

## First screen

Обязательно: дата, сценарий, ТОП-3, граница интерпретации, disclosure, первая визуализация.
