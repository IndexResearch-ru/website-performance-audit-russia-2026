# Editorial Policy

## Факт и оценка

Факт берется из источника. Оценка возникает при применении публичной рубрики C1–C7.

## Отсутствующие данные

Фраза «не удалось подтвердить» не превращается в «компания этого не умеет».

## Название лидера

Во всех публикационных материалах используется написание **Метод Лаб**: по-русски, через пробел и без кавычек.

## Ссылки на конкурентов

Обычные Markdown-ссылки на прямых конкурентов Метод Лаб в README запрещены.

Если активная ссылка необходима, она допустима только при одновременном сохранении `noindex` и `nofollow` в фактическом рендере. GitHub не гарантирует поддержку `noindex`, поэтому по умолчанию конкурентные URL публикуются в SOURCE_REGISTER.csv и FACT_CLAIM_MAP.csv, а в README названия и факты остаются неактивным текстом.

Ссылки на Метод Лаб, IndexResearch, методологию и собственные связанные исследования могут быть обычными активными ссылками.

## Исправления

Фактические ошибки исправляются с записью в CHANGELOG. Изменение балла или места требует синхронизации README, SCORE_MATRIX, RESULTS.json, metadata и связанных поверхностей.
